## Phase 4 — simplify architecture only where it pays back

- [ ] **P2 · Architecture · Verified — complete or stop the Nest/legacy split.** Most Nest services are thin wrappers around `server/src/services/*` and `server/src/db/database.ts`; behavior is duplicated across controller-level permission/audit/event code. Establish one domain boundary at a time (start with Trips/Days/Places), move access checks, transactions, events, and DTO validation into it, then delete the unused legacy route path. Acceptance: one authoritative implementation per mutation and API contract tests pass unchanged.

- [ ] **P2 · API/Types · Verified — promote shared Zod contracts from dev warnings to enforced boundaries.** `client/src/api/client.ts` validates only selected responses in development and intentionally passes malformed production data through. Expand shared request/response schemas by domain, validate server inputs at controllers and parse client responses at high-risk boundaries with graceful error UI. Acceptance: contract drift fails CI and results in a useful user-visible recovery state rather than undefined UI behavior.

- [ ] **P2 · Observability · Measure — add privacy-safe operational signals.** The app has audit logs and health routes but no demonstrated latency/error/SLO view for maps, imports, sync queue, WebSocket reconnects, or SQLite contention. Add structured logs and lightweight counters locally first; avoid a paid telemetry dependency. Acceptance: an operator can answer which external provider failed, which job is stuck, and whether a slow request is DB, provider, or upload related without logging travel content/tokens.

## Audit notes / non-actions

- The current PWA policy deliberately keeps API responses `NetworkOnly` in Workbox because caching them by URL could leak data between users on shared devices. Preserve that boundary; improve the per-user IndexedDB repository instead.
- Map photo fetching already has a bounded concurrency queue and map service calls route through an SSRF guard. Do not add a second generic request cache until provider-specific hit rates, quotas, and invalidation needs are measured.
- The repository has mature Playwright capture artifacts under `client/e2e/.tmp/shots/` and visual baselines. Extend these for changed workflows instead of introducing another visual-testing tool.
